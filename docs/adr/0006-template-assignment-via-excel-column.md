# Template assignment routes recipients via an Excel column, mapped at generate time

A Generate Job can route different recipients to different Document Templates through a "template" column in the imported Excel: at generate time the app lists the distinct values in that column and the user assigns each value to a template, with a default template covering blank values, and unassigned values fail fast with the affected recipients listed. The output naming pattern stays shared across all templates in the job. We chose this over storing the value-to-template mapping on the template itself because the mapping is per-campaign, not per-template — the same variant template matches different Excel values across campaigns — and over manual per-recipient assignment because that is too slow for hundreds of rows. The fail-fast behavior exists so a job never silently produces output with a wrong or missing template.
